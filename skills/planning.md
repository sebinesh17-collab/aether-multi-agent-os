# Planning skill

1. Read the user brief and every supplied artifact before proposing implementation.
2. Extract explicit requirements, constraints, assumptions, acceptance criteria, and unknowns.
3. Split the work into independently verifiable tasks with dependencies and owners.
4. Cover discovery, design, implementation, integration, tests, security, performance, documentation, deployment, and acceptance.
5. Do not confuse a generated task record with completed work. Record evidence for every completion.
