# Aether Skillbook

Skills are reusable operating procedures loaded into agent tasks as needed. The current release includes the following playbooks:

- `planning.md`: requirement discovery and work breakdown.
- `architecture.md`: system design and ADR writing.
- `frontend.md`: accessible, responsive vanilla web UI.
- `backend.md`: API and service implementation.
- `security.md`: threat modelling and secret handling.
- `testing.md`: unit, integration, and acceptance test plans.
- `devops.md`: reproducible builds and deployment checks.
- `files.md`: safe source-file analysis and evidence traceability.
- `decision-making.md`: debate, escalation, and auditable arbitration.
