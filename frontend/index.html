INTEGRATIONS & SECURITY
Settings
Secrets are encrypted before database storage and are never displayed after saving.
Built-in tool catalog
Tools available to the workspace services.
Tool descriptions load when requested.
AI provider
Supports OpenAI-compatible chat completions endpoints.


Firebase Storage
Use a dedicated service account with only the storage permissions required.
Email delivery
Configure SMTP variables in the server .env file (SMTP_HOST, SMTP_PORT, SMTP_USERNAME, SMTP_PASSWORD, SMTP_FROM). The completion email is sent when all tasks have reached a terminal state.
Cloud terminal
Disabled by default. Configure a remote, isolated sandbox in server environment variables. Do not expose a host Docker socket to this app.
